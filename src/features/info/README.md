# Info feature

Public and in-app informational pages: Help centre, Privacy Policy, and Terms of Service, plus shared static reference constants (support email and district list).

## Purpose
- `/help` and in-app role help pages (`/customer/help`, `/merchant/help`, `/courier/help`, `/dispatcher/help`, `/admin/help`)
- `/privacy`
- `/terms`

## Ownership
Frontend-only content and shared reference constants.
